SalesAnalytics

Proyecto académico desarrollado con C# y .NET para trabajar con análisis de ventas, estructura backend y manejo de datos. El sistema está organizado por capas e incluye módulos relacionados con API, aplicación, dominio, persistencia, ETL y presentación web.

Tecnologías utilizadas
C#
.NET
SQL
Entity Framework Core
Base de datos relacional
Git y GitHub
Visual Studio
Funcionalidades principales
Organización del proyecto por capas.
Manejo de datos relacionados con ventas.
Conexión a base de datos.
Separación entre dominio, aplicación, persistencia y API.
Módulo ETL para procesamiento o carga de información.
Estructura preparada para exponer datos mediante API.
Objetivo del proyecto

El objetivo de este proyecto es practicar el desarrollo de aplicaciones backend con .NET, manejo de datos, persistencia y separación de responsabilidades dentro de una solución más organizada.

Estructura del proyecto
Api: capa encargada de exponer servicios y endpoints.
Application: lógica de aplicación.
Domain: entidades y reglas principales.
Persistence: acceso y configuración de datos.
Etl: procesamiento o carga de datos.
Web: presentación o consumo de información.
Estado del proyecto

Proyecto académico en desarrollo/mejora continua.
